# تحديث الاستوديو (v1.6.0)

## ما أُضيف فعلياً
- **التبويبات**: المعرض، الصور، الفيديوهات، الألبومات، المفضلة، الدراسة الطبية، المحذوفات، التخزين.
- **التجميع بالتاريخ** (اليوم / أمس / التاريخ) + الفرز بالأحدث أو الحجم أو الاسم.
- **المفضلة**: من العارض أو بالتحديد المتعدد؛ تظهر علامة قلب على الصورة المصغرة.
- **سلة المحذوفات**: الحذف ينقل إلى السلة (استعادة / حذف نهائي / إفراغ)، وتُمسح تلقائياً بعد 30 يوماً.
- **منع التكرار**: بصمة SHA-1 أثناء الاستيراد؛ الملف المطابق يُتخطى مع رسالة.
- **حذف الألبوم لا يحذف الملفات**: تعود إلى المعرض الرئيسي.
- **العارض**: زر مفضلة + مشاركة + تاريخ الإضافة.
- **الفيديو**: حفظ آخر موضع ومتابعة المشاهدة تلقائياً.
- **التخزين**: المساحة المستخدمة/المتبقية/حجم السلة وأكبر 15 ملفاً.

## الملفات المعدلة
StudioStore, StudioMediaSection, StudioScreen, StudioGrid, MediaViewerScreen, VideoPlayerView, app/build.gradle.
بيانات المستخدم القديمة تبقى كما هي (الحقول الجديدة اختيارية في index.json).

## لم يُنفَّذ بعد
محرر الصور، قفل التطبيق/المجلدات بالبصمة، النسخ الاحتياطي والاستعادة، البحث في الدراسة، تطوير قسم المانها، لوحة الرئيسية الجديدة.

> لم يُبنَ المشروع هنا (لا يوجد JDK/Android SDK). ابنِه عبر BUILD_APK.sh أو GitHub Actions وأرسل أي خطأ لأصلحه.
