# الدفاتر (1.7.0)

## أين تظهر
الأستوديو ← «الدراسة الطبية» ← «الدفاتر». لم يُضف قسم جديد؛ هي نفس الشاشة القديمة بشكل جديد.

## الملفات
- جديدة: `BookModel.java` (نموذج الصفحات، بلا اعتماد على أندرويد)، `BookScreen.java` (الأغلفة والصفحات وتقليب الصفحات وأنواع الدفاتر ووضع الاختبار)، وأيقونات `ic_help` `ic_study` `ic_tasks` `ic_eye` `ic_eye_off` `ic_up` `ic_down` `ic_text` `ic_page_add` `ic_star`.
- معدّلة: `StudioStore.java` (نوع الدفتر ولونه + ملف صفحات لكل دفتر)، `MedicalScreen.java` (رف الأغلفة ونافذة الإنشاء وفتح الدفتر)، `StudioBackup.java` (إدراج ملفات الصفحات في النسخة الاحتياطية)، `app/build.gradle` (الإصدار).

## التخزين
- صفحات كل دفتر: `files/studio/books/<id>.json` (كتابة ذرية + نسخة `.bak`).
- نوع الدفتر ولون الغلاف: حقلان جديدان في `index.json`. الدفاتر القديمة بلا حقل تُقرأ كدفاتر «كتابة حرة».
- الصور داخل الصفحات تُحفظ في `media/` كما كانت صور الدفتر.
- لا حذف لأي بيانات قديمة: الملاحظات والصور القديمة للدفتر تبقى متاحة من قائمة ⋯ ← «الملاحظات والصور السابقة».

## اختبار المنطق
`tools/book-tests/` يحتوي اختبار JVM لـ `BookModel` (الترقيم، الحذف، النقل، الحفظ والتحميل). شغّله بـ JDK عادي.
